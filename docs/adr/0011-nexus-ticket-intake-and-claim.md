# 0011 Nexus 工单导入和部门领取

## 背景

Nexus 以至少一次投递跨系统发送工单。FlowOps 需要识别重放，将工单路由到固定租户及部门，并保证同部门客服竞争时只产生一次领取历史。

## 备选方案和决定

| 决策 | 备选方案 | 当前选择与取舍 |
| --- | --- | --- |
| 接入身份 | 共享凭据搭配请求内路由、每个接入使用独立绑定 | 使用独立绑定，密钥轮换时保留租户和部门路由。增加接入配置行，让权限边界与接入身份一致。 |
| 幂等和回执 | 先写消息队列再异步建单、在同一 MySQL 事务内导入并返回回执 | 同步事务以唯一索引约束外部单号和事件 ID，回执可直接携带已提交的工单号。该请求须等待 MySQL 提交。 |
| 领取并发 | 先锁定工单再检查、按租户和部门以版本及状态做条件更新 | 使用条件更新与既有乐观锁语义。竞争失败返回 409，成功方在同一事务写流转和分派记录。 |

## 后续重评条件

出现导入延迟无法满足 Nexus 投递超时、共享接入需要动态路由，或同一工单出现长期重度写竞争时，重新评估接入协议和并发方案。
